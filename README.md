# BOT-HUNTER

## SniperFx stop-and-reverse grid EA

`SniperFxStopReverseGrid.mq4` is an MT4 Expert Advisor reconstructed from the
recorded behavior: fixed 0.01-lot directional grid entries, basket-level
profit locking, and one opposite stop order that reverses the basket.

The exact source settings could not be recovered from the recording. Test on a
demo account and tune all point-based inputs for the broker's XAUUSD digits,
spread, stop level, and contract specification before live use.
